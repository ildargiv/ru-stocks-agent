Инвесткомитет

ИИ-аналитик акций Мосбиржи, который работает как ваш инвестиционный отдел: следит за списком бумаг, копит отчёты и новости в папке каждой акции и выносит решение на инвесткомитет с адвокатом дьявола.

!

Не является индивидуальной инвестиционной рекомендацией. Агент даёт аналитику и образовательную информацию. Решения о сделках вы принимаете сами. Модель может ошибаться: проверяйте ключевые цифры по первоисточникам. Агент не совершает сделок и не просит доступ к брокерскому счёту.

Возможности

Что умеет агент

Список наблюдения

«Следи за Сбером» — бумага на наблюдении и сразу первичный глубокий разбор. Бумаг сколько угодно.

Папка на акцию

МСФО/РСБУ, новости, цены, дивиденды, тезис и протоколы копятся в ~/stocks-desk/<ТИКЕР>/. Каждый разбор опирается на прошлый.

Инвесткомитет

Отраслевой аналитик, инвестор, риск-менеджер, дивиденды и корпоративное управление, макро. Адвокат дьявола атакует, итог — голосование.

Оценка

Мультипликаторы, DCF в трёх сценариях, обратный DCF, модель Гордона, чувствительность.

Живые данные

MOEX ISS, ГИР БО ФНС, e-disclosure, cbr.ru, отчёты компаний, новости и форумы с проверкой.

Расписание

«Каждый будний день в 19:00 проверяй мой список и пиши только важное» — cron Hermes, OpenClaw, задачи Claude.

Установка

Одна команда для каждой среды

Навык по открытому стандарту Agent Skills (SKILL.md). Нужен Python 3.9+, только стандартная библиотека и pypdf для PDF.

$ git clone https://github.com/ildargiv/ru-stocks-agent.git && cd ru-stocks-agent
$ ./install.sh claude
