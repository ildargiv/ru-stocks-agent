# Шаблоны

## 1. Протокол инвесткомитета → `analyses/<YYYY-MM-DD>-committee.md`

```markdown
# Инвесткомитет: <ТИКЕР> — <Компания> — <YYYY-MM-DD>

## Решение
**<Покупать / Накапливать / Держать / Сокращать / Избегать / Нет мнения>** · скоринг <NN>/100 · уверенность <1–5>
Цена <X> ₽ (MOEX, <дата/время>) · справедливая стоимость: медведь <A> ₽ / база <B> ₽ / бык <C> ₽ · потенциал к базе <±%> + дивиденды <Y%> за 12 мес.
Голоса: покупать N · держать N · сокращать N · избегать N
TL;DR: <3–4 предложения: почему, главный аргумент за, главный против, что изменит решение>
Прошлое решение: <дата, вердикт, цена> → <что изменилось>

## Брифинг
<что за компания, что изменилось, какой вопрос решали>

## Факты (с источниками)
| Показатель | Значение | Период | Источник |
|---|---|---|---|
| Капитализация / EV | | | |
| Выручка, EBITDA, ЧП (LTM, г/г) | | | |
| FCF, чистый долг/EBITDA | | | |
| P/E, EV/EBITDA, P/B, дивдоходность — против 5-летней медианы и аналогов | | | |
| Ключевые отраслевые метрики | | | |

## Мнения экспертов (независимые)
### Отраслевой аналитик — <позиция>, уверенность <n>
### Долгосрочный инвестор — <позиция>, уверенность <n>
### Риск-менеджер — <позиция>, уверенность <n>
### Дивиденды и корпоративное управление — <позиция>, уверенность <n>
### Макроэкономист — <позиция>, уверенность <n>
(в каждом: 3 аргумента с цифрами и источниками, главная неопределённость)

## Адвокат дьявола
**Главный медвежий аргумент:** <одна фраза>
| Риск | Вероятность | Ущерб для цены | Чем подтверждается |
|---|---|---|---|
Вопросы без ответа: …
Медвежья цена: <₽>

## Ответы на атаку
<эксперт → по существу: принял / опроверг фактом / скорректировал оценку>

## Оценка
<мультипликаторы против истории и аналогов; DCF 3 сценария с допущениями; обратный DCF; дивмодель; таблица чувствительности>

## Дивиденды
<политика, прогноз DPS на 12 мес. база/риск, ближайшая отсечка, покрытие FCF>

## Сигналы сообщества
<таблица со статусами ✅/❌/⚠️/💬>

## Голосование
| Эксперт | Позиция | Уверенность |
|---|---|---|

## Решение председателя
- Почему так: …
- Особое мнение: …
- Максимальная доля в портфеле (риск-менеджер): …
- Стоп-условия / выход: …

## Триггеры пересмотра
- [ ] <событие или порог, напр. «payout < 50% МСФО», «ЧД/EBITDA > 2,5», «цена > 350 ₽»>

## Что проверить в следующем отчёте (<дата отчёта>)
- …

## Источники
<все URL и файлы папки, использованные в разборе>

_Аналитика и образовательная информация, не индивидуальная инвестиционная рекомендация._
```

## 2. Сводка по обновлению (без комитета)
```
**<ТИКЕР>** <цена> ₽ (<±% с разбора <дата>>, IMOEX <±%>) · вердикт комитета: <…>
Что нового: <1–3 пункта с источниками и статусом проверки>
Тезис: не задет / задет триггер «…» → созываю комитет
Ближайшее: <отчёт / СД / отсечка — даты>
```

## 3. Сводка по списку
```
| Тикер | Цена | С разбора | Вердикт | Что случилось | Действие |
|---|---|---|---|---|---|
```
Ниже — подробности только по строкам, где «Действие» не пусто.

## 4. Ежедневный брифинг семейного офиса → `_portfolio/briefs/<YYYY-MM-DD>.md`
```markdown
# Брифинг семейного офиса — сессия <YYYY-MM-DD>

## TL;DR (CIO)
<2–4 строки: портфель ±X% против IMOEX ±Y%; главное событие дня; нужно ли действие владельца>

## Портфель за день
Стоимость <₽> · за день <±₽ / ±%> · против IMOEX <±п.п.> · с начала владения <±₽ / ±%> (если заданы количество и средняя цена)
| Тикер | Цена | День | vs IMOEX | Оборот/ср20 | Доля | Вклад, п.п. | Что случилось (источник, статус ✅/⚠️/💬) |
|---|---|---|---|---|---|---|---|

## Почему двигались (трейдер и аналитики)
- **<ТИКЕР> ±X%** — <причина: новость / сектор (индекс ±%) / весь рынок / дивгэп / причина не найдена>; тезис: не задет / задет «…»

## Новости и раскрытие (проверенные)
- <ТИКЕР>: <факт> — <первоисточник, дата> ✅

## Фон рынка (макростратег)
IMOEX, секторные индексы, ОФЗ (RGBI), юань, курсы ЦБ, Brent — одной-двумя строками, только то, что повлияло на портфель.

## Риск (риск-менеджер)
Концентрация (макс. доля, топ-3, эффективное число бумаг), просадки, отклонения от целевых долей, связанные бумаги.

## Календарь на 14 дней
| Дата | Тикер | Событие | Что важно (для отсечки — последний день покупки) |
|---|---|---|---|

## Вопрос адвоката дьявола
<один вопрос, с цифрой>

## Что обсудить владельцу
- <вариант действий и аргументы — не приказ>

## Эскалация в инвесткомитет
- <ТИКЕР>: <причина> → протокол analyses/<дата>-committee.md / в очереди

_Источники: MOEX ISS (portfolio.py session, <время>), …. Аналитика, не индивидуальная инвестиционная рекомендация._
```

Короткое сообщение владельцу (тихий день — только первые две строки):
```
📊 Портфель <±X%> (IMOEX <±Y%>) · <стоимость, ±₽ за день>
Главное: <1–3 пункта: бумага — что случилось — значение для тезиса>
Скоро: <отсечка/отчёт/ЦБ — дата>
Нужно ваше решение: <да — что / нет>
Полный брифинг: <путь к файлу>
```
