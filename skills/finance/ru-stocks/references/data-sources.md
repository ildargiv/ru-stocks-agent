# Где брать информацию по акциям РФ

Приоритет: **первоисточник** (биржа, раскрытие компании, ЦБ, ФНС) > агрегатор > СМИ > аналитика брокеров (мнение) > форумы (гипотезы).
Всегда фиксируй дату данных.

## 1. Рынок
| Источник | URL | Что брать |
|---|---|---|
| **MOEX ISS API** (бесплатно, без ключа, задержка ~15 мин) | `iss.moex.com/iss/...` | Используется скриптами |
| — поиск | `/iss/securities.json?q=<тикер/название>` | SECID, ISIN, эмитент, **ИНН** |
| — котировка | `/iss/engines/stock/markets/shares/boards/TQBR/securities/<SECID>.json` | цена, bid/ask, оборот, капитализация |
| — история | `/iss/history/engines/stock/markets/shares/boards/TQBR/securities/<SECID>.json?from=YYYY-MM-DD` | дневные цены и обороты |
| — дивиденды | `/iss/securities/<SECID>/dividends.json` | история отсечек и сумм (бывает неполной — сверяй с компанией) |
| — индекс | `/iss/history/engines/stock/markets/index/boards/SNDX/securities/IMOEX.json` | IMOEX, отраслевые индексы (MOEXOG, MOEXFN, MOEXMM…) |
| Сайт биржи | moex.com/ru/issue.aspx?code=SECID | параметры, уровень листинга, документы |
| Smart-Lab | smart-lab.ru/q/<SECID>/f/y/ | сводные МСФО за годы, мультипликаторы, сравнение с сектором (вторичный источник — сверять) |
| Доход | dohod.ru/ik/analytics/dividend/<тикер> | дивиденды, прогнозы, индекс DSI |
| Investing, TradingView, Финам | | графики, консенсус-прогнозы, календари |

## 2. Компания: отчётность и раскрытие
| Источник | Что брать | Примечание |
|---|---|---|
| **Сайт компании → «Инвесторам/Акционерам»** | МСФО (квартал/полугодие/год), презентации, пресс-релизы, годовой отчёт, дивполитика, устав, записи звонков, Investor Day | Часто первый источник цифр |
| **e-disclosure.ru** (поиск по ИНН/названию) | Существенные факты: решения СД и ГОСА, дивиденды (рекомендация → решение → отсечка), сделки, изменения в капитале, байбэк, допэмиссии; МСФО и РСБУ | Главный официальный источник событий |
| **ГИР БО ФНС** (bo.nalog.gov.ru) | РСБУ юрлица по годам с аудитом | `gir_bo.py`; нет банков |
| **ЦБ (банки)** | cbr.ru/banking_sector/credit/ — формы 101/102/123/135 ежемесячно | Ранний индикатор прибыли банка до МСФО |
| ЕГРЮЛ, checko/rusprofile | собственники, «дочки», связанность | |
| kad.arbitr.ru, fedresurs.ru | иски, банкротства «дочек», налоговые споры | |
| Санкционные списки (OFAC SDN, ЕС, UK) | статус компании и основных акционеров | |

**Порядок поиска свежего отчёта:** 1) сайт компании → пресс-релиз и презентация (появляются раньше PDF) → МСФО PDF; 2) e-disclosure → «Отчётность»; 3) веб-поиск `"<компания>" МСФО 9 месяцев 2026` / `"<компания>" результаты 3 квартал 2026`. Убедись, что период свежий, а не прошлогодний.

## 3. Макро и ставка
| Источник | Что брать |
|---|---|
| **Банк России** (cbr.ru) | Ключевая ставка и календарь заседаний, сигнал, среднесрочный прогноз, макроэкономический опрос (консенсус), КБД ОФЗ, инфляционные ожидания |
| Минфин, Минэкономразвития | Бюджет, налоговые инициативы (НДПИ, пошлины, налог на прибыль), сценарные условия |
| Росстат | Инфляция, промпроизводство, розница |
| Цены сырья | Urals/Brent, газ TTF/Henry Hub, металлы LME, удобрения, уголь — с датой |
| Курс | cbr.ru (официальный), биржевой CNYRUB_TOM |

## 4. Новости
Интерфакс, ПРАЙМ, ТАСС, РБК, Коммерсантъ, Ведомости, Frank Media, The Bell, Reuters/Bloomberg (с осторожностью к доступности), отраслевые (Нефтегаз.ру, Металлоснабжение, Retail.ru, ComNews, CNews). Скрипт `news.py` собирает их через Google News RSS; свои RSS добавляются `--add-feed`.

## 5. Аналитика (мнение, не факт)
Брокеры и банки: БКС, Т-Инвестиции, Альфа, Сбер CIB, ВТБ Мои Инвестиции, Газпромбанк, Финам, АТОН, Ренессанс, Совкомбанк, Цифра брокер, Доход — целевые цены и рекомендации, консенсус. Использовать как ориентир «что ждёт рынок» и чтобы найти аргументы, которые комитет пропустил. Помнить о конфликте интересов (организаторы SPO/IPO).

## 6. Сообщество
Smart-Lab (форум и блоги), Пульс (Т-Инвестиции), Telegram-каналы, YouTube-разборы, VC.ru. Протокол — `news-forums.md`.

## 7. Налоги и правила
НДФЛ на дивиденды и курсовую разницу (прогрессивная шкала — проверяй актуальную), ЛДВ (3 года), ИИС-3, ограничения для неквалов (тестирование), счета типа С — проверяй актуальные редакции НК РФ и правил ЦБ.
